# Setting Sun

This is nothing more than a re-packaging of the original
[source](https://smallpond.ca/jim/misc/settingSun/index.html).
All needed resources (e.g. images) are combined into a single
file, so no web server is required. Some text is also removed,
which prevents scrolling and makes
[playing on a mobile device] (https://deverac.github.io/setting-sun/)
more pleasant than the original.


The source website has a
[solution](https://smallpond.ca/jim/misc/settingSun/solution.html)
which is 112 steps.
Per Wikipedia, the minimum number of moves required to solve the puzzle
is 81. (Moving a single piece to any reachable position is a single move.)
